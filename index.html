Step-By-Step Walkthrough

Bring Your Own Credentials (BYOC) Guide

How to configure your own free Google Cloud Project for the Pro Bot. No coding or prior experience required.

🛡️

Are My Client ID and Secret Safe with DS GDrive?

Yes, 100% safe. Your Client ID and Client Secret do not contain your files, passwords, or personal account data. They act purely as an authorized digital ID card that tells Google: "This application is allowed to ask for Drive access."

Having these credentials alone is never sufficient to access your files. Access is only established when you complete Google's official OAuth consent screen and approve the connection yourself.

Always store your downloaded credentials JSON file securely on your own device. You remain in control and can revoke access via your Google Security dashboard anytime.

1

Create a New Google Cloud Project

Open the official Google Cloud Console and sign in with your Google account.

Click the project dropdown in the top header (it may display an existing project or say "Select a project"). Click New Project in the top right of the modal. Name it DS GDrive Pro and click Create. Wait 5-10 seconds for Google to initialize the project, then make sure it is selected in the top bar.

2

Enable the Google Drive API

Open the left navigation menu (hamburger icon on the top left) and click APIs & Services > Library.

In the search bar, type Google Drive API and press enter. Select the Google Drive API card and click the blue Enable button.

3

Configure the OAuth Consent Screen & Publish

In the left sidebar, navigate to APIs & Services > OAuth consent screen.

Choose External under User Type and click Create.

Fill in the required fields: set an App Name (e.g., DS GDrive Pro), pick your own email for "User support email", and enter your email at the bottom under "Developer contact information". Leave the rest blank and click Save and Continue through the Scopes and Test Users screens.

Crucial Step: Once back on the OAuth Consent summary dashboard, find "Publishing status" and click the Publish App button to confirm. This makes sure your login token does not expire every 7 days!

4

Create Desktop Application Credentials

In the left sidebar, click Credentials.

Click + Create Credentials at the top of the screen and choose OAuth client ID.

Important: In the "Application type" dropdown, you MUST select "Desktop app" (Desktop application). Do not pick Web application.

Set a name (or keep the default) and click Create.

5

Download the JSON File & Start the Pro Bot

A modal titled "OAuth client created" will pop up. Click the Download JSON button.

Open @DS_GDrive_Pro_bot on Telegram, run /start, and send this downloaded JSON file when requested. You will be authenticated immediately!
